# タスク台帳

グループ分け・着手日/終了日・4段階ステータス（未着手・遂行中・完了・保留）・サブタスクでタスクを管理する ToDo アプリ。
Claude のアーティファクトとして公開しており、データはアーティファクトのデータ保存領域（`db` capability）に保存される。

- `index.html` — アプリ本体（公開ページのソース）

## 変更履歴
- 日本の祝日データをインターネット上の公開データ（holiday_jp、jsDelivr 経由）から取得するよう変更。取得できない場合と範囲外の年は計算で表示
- 日本の祝日（振替休日・国民の休日を含む、アプリ内で計算）と会社休日（手動登録、期間指定可）をガントチャートに表示。リストの期間表示とバーのヒントに稼働日数を追加
- ガントチャート表示を追加（リストと切り替え。日／週の表示単位、今日の線、土日の網掛け、サブタスク進捗の塗り、バーから編集）
- サブタスクのいずれかにチェックが入ったら、未着手・保留の親タスクを自動で「遂行中」にする連動を追加
- タスクとグループの複製機能を追加（編集画面から。ステータスとサブタスクのチェックを未着手に戻すかを選べる）
- サブタスクがすべて完了したら親タスクを自動で「完了」に、完了済みの親で未完了のサブタスクが出たら「遂行中」に戻す連動を追加
- サブタスク機能を追加
- 初版（グループ、着手日・終了日、ステータス）
