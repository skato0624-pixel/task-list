# タスク台帳

グループ分け・着手日/終了日・4段階ステータス（未着手・遂行中・完了・保留）・サブタスクでタスクを管理する ToDo アプリ。
Claude のアーティファクトとして公開しており、データはアーティファクトのデータ保存領域（`db` capability）に保存される。

- `index.html` — アプリ本体（公開ページのソース）

## 祝日データの更新手順
1. `npm pack @holiday-jp/holiday_jp` で最新版を取得
2. `lib/holidays.js` から 2020〜2050年の `{日付: 名前}` を作り、`{source, version, url, fetchedAt, from, to, days}` としてアプリのデータ `settings/jpHolidays` に上書き保存

## 変更履歴
- 左のグループ欄でもグループのドラッグ並べ替え（↑↓キー対応）と「⋯」メニュー（編集・複製・アーカイブ・削除）を使えるように
- サブタスクを完了にした日時を記録（各サブタスクの横に表示。チェック・チェック外しの履歴をコメント欄の時系列に表示）
- タスクのステータス変更履歴を記録（変更前→変更後と日時、サブタスク連動による自動変更も区別）。編集画面とコメント欄に表示
- タスクごとのコメント機能を追加（日時付きで投稿・編集・削除、新しい順に表示。Ctrl+Enter で投稿）
- グループとタスクをドラッグで並べ替え（タスクは別グループへの移動も可、↑↓キーでも移動）。並び順に「手動（ドラッグ順）」を追加し、最初のドラッグで自動的に切り替え
- 左のグループ欄の「アーカイブ」をもう一度押すと、展開したアーカイブ済みグループの一覧を閉じられるように
- グループ削除時に確認画面を表示し、中のタスクを「未分類に移す」か「一緒に削除する」かを選べるように
- 編集画面から複製ボタンを外し、複製は「⋯」メニューからに一本化
- グループのアーカイブ機能を追加（⋯メニューからアーカイブ／戻す。「すべて」・集計・ガントから除外し、左の「アーカイブ」にまとめて表示）
- リスト表示のグループとタスクの「編集」ボタンを「⋯」メニューに変更（編集・複製・削除。削除は2回押しで確定）
- ガントチャートの日付見出し：土日は文字色を平日と同じにし、背景をチャートと同じグレーに。祝日は赤文字のまま背景をチャートと同じ色に
- 休日設定の祝日一覧で今年の日付の「月」が欠けて表示される不具合を修正
- 日本の祝日データをインターネット上の公開データ（holiday_jp）から取得するよう変更。ページからの CDN 読み込みは閲覧環境で遮断されたため、Claude が npm レジストリから最新版を取得してアプリのデータ（settings/jpHolidays）に保存し、ページはそれを読む方式にした。範囲外の年とデータ未取り込み時は計算で表示
- 日本の祝日（振替休日・国民の休日を含む、アプリ内で計算）と会社休日（手動登録、期間指定可）をガントチャートに表示。リストの期間表示とバーのヒントに稼働日数を追加
- ガントチャート表示を追加（リストと切り替え。日／週の表示単位、今日の線、土日の網掛け、サブタスク進捗の塗り、バーから編集）
- サブタスクのいずれかにチェックが入ったら、未着手・保留の親タスクを自動で「遂行中」にする連動を追加
- タスクとグループの複製機能を追加（編集画面から。ステータスとサブタスクのチェックを未着手に戻すかを選べる）
- サブタスクがすべて完了したら親タスクを自動で「完了」に、完了済みの親で未完了のサブタスクが出たら「遂行中」に戻す連動を追加
- サブタスク機能を追加
- 初版（グループ、着手日・終了日、ステータス）
